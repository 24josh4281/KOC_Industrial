# ORS 동일 자료 재실행 방지 검증

## 변경 범위

- 다운로드한 ORS Excel/ZIP, 기준 Excel, 설정, 프로그램 판본, 검증 완료 결과 파일의 SHA-256을 로컬 실행 장부에 기록한다. 변경이 없으면 이전 결과를 그대로 연다.
- 실패 기록이 있는 동일 입력은 자동으로 다시 처리하지 않는다. 손상된 ZIP도 입력 해시를 기록한 뒤 실패 처리할 수 있다. 미래 날짜 자료의 판정은 한국시간의 사용 가능일에 다시 검사한다.
- 과거에 완료된 결과는 원본 해시·자료 목록·JSON 계약·웹 내장 자료·기존 검사 기록을 다시 대조한 후 재생성 없이 장부에 등록했다.

## 실제 확인

- Python 전체 72개, 웹 Node 24개 검사 통과.
- 현재 로컬 결과 3,419원장행과 12개 필터 조건의 Python/JavaScript 집계 전체 결과가 일치했다.
- 완료된 기존 결과 등록 성공. 그 뒤 `--apply` 1회 실행 결과는 `skipped_unchanged`였다.
- 현재 결과 지정 파일, 엑셀 2개, JSON, HTML, 최근 결과 링크의 해시가 실행 전후 일치했다. 새 실행 폴더도 생기지 않았다. 장부에 결과 파일 11개의 해시가 기록됐고 실패 기록은 없다.
- 이번 확인에서 Excel 재계산과 React 재빌드는 실행하지 않았다. 대시보드 집계 로직과 웹 빌드 파일은 변경하지 않았다.

## 판단 경계

- 입력 자료는 기존과 동일하다. 오래된 ORS 자료가 현재 관리 기준값을 덮어쓴 것으로 해석하지 않는다.
- 계산 근거가 없는 396셀은 사용자 확인에 따라 `기준 미확인`으로 유지한다. 숫자 복원은 실행하지 않았다.
- 새 파일을 내려받아 입력 폴더에 추가한 후의 실제 Excel 갱신, DB 연결, 외부 알림 발송, 공개 배포는 이번 검증에서 실행하지 않았다.
