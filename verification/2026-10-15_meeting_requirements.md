# 회의 요구사항 대조 및 비공개 처리상태 매핑 수정

첨부 회의록과 제품 기술서의 누적 실적·현재 진행관리 요구를 로컬 v8과 대조했다. 기존 신청연도 조회는 전 기간의 현재 미종결 조회와 구분해야 한다. 회차·기관 인계·SLA가 미확정이므로 공식 승인율이나 법정 지연을 추정하지 않는다.

## 공통 소스 수정

`config/management_views.json`의 `(비공개)국외평가.status`를 11열에서 5열, `(비공개)국외인증.status`를 16열에서 10열로 변경했다. 기존 연결은 관련 사업의 상태/이력을 참조했고, 새 연결은 해당 비공개 신청의 원본 진행상태다. 내부 단계 열은 보존한다. 원본 Excel·수식·숫자를 수정하지 않는다. 표준 dataset·SQL 계약 변경은 없다.

합성 fixture에서 비공개 상태와 다른 업무 상태가 충돌하는 상황을 회귀검사에 추가했다. 웹 검사 29개 통과, 실제 자료의 Python/JS 원장 전체 및 12조건 일치, Vite 빌드 성공. 기존 dependency directive 및 bundle size 경고는 빌드 실패가 아니다.

## 로컬 산출물

별도 v9 Excel·독립 HTML·요구사항 검증 보고서와 ORS 스냅샷 저장소를 저장소 밖에 생성했다. 내부 상세와 수량은 해당 로컬 보고서만 참조한다. 실제 Excel 16 읽기 전용 재계산·필터, Edge 데스크톱/모바일 조작을 검증했다. 동일 내용의 수령 파일도 수령 건별 기록을 남기되 원문 내용은 해시로 중복 보관하지 않는다. 원본 4개 해시 보존을 확인했다.

이번 변경은 기존 ORS 자동반영 포인터를 변경하지 않는다. 공개 push·배포·DB 서버·인증·공동편집은 실행하지 않았다. 신규 회차 자동 확정·규정 기한·공식 승인 실적은 담당자 기준 확정 후의 남은 범위다.
