# 자료 탐색·문서·디자인 검증

로컬 기능 브랜치 `feature/all-materials-reports-design`. 기존 공개 배포 결과와 이번 변경의 검증 결과를 구분한다.

## 실행한 검사

- `python -m unittest discover -s tests -v`: 37개 통과.
- `node --test tests/web.test.mjs tests/materials.test.mjs`: 20개 통과.
- 전체 Python/JS 결과 비교: 공개 분석 79조건, 표준 원장 96조건, 기한 12조건, 자료 요약 합성 3조건. 로컬 원장 요약도 동일함을 확인했다. 내부 데이터와 결과는 공개 저장소에 포함하지 않는다.
- React/Vite 프로덕션 빌드 성공. TanStack의 `use client` 지시문 무시 안내와 500 KB 이상 번들 경고는 남아 있다. 빌드 오류는 아니다.
- 공개·자료목록·사용 설명서·인사이트 4개 화면의 React 초기 HTML 생성 검사 통과. 브라우저 조작 시험을 대체하지 않는다.
- 새 로컬 JSON을 `local_materials.schema.json`으로 검사했다. 로컬 HTML의 JSON 왕복 동일성, 외부 script/link 의존성 없음, 네트워크 차단 정책을 확인했다.
- 새 통합 엑셀 19조건 재계산 결과와 웹 계산 일치. 저장한 신청 값 보존·새 파일 계산 오류 없음·차트·원본 해시 확인. 생성 도구에서 시트별 렌더 확인.
- 인사이트 PDF와 사용 설명서 PDF 전 페이지 렌더 및 한글·표·줄바꿈 확인. 공개 설명서에 내부 신청 ID·원본 파일명이 포함되지 않은 것을 확인했다.
- `scripts/stage_public_site.py`: 공개 XLSX 2개와 사용 설명서 PDF만 허용목록으로 복사. 공개 JS에서 내부 신청 ID·원본 파일명 미검출. 실제 내부 데이터는 공개 파일 import 대상이 아니다.
- `git diff --check`: 통과.

## 실행하지 않은 검사·운영

- 이번 변경의 원격 push, 원격 CI, Pages 배포: 엑셀 검토 후 게시 요청에 따라 승인 전.
- 새 화면의 실제 브라우저 상호작용/모바일 화면 확인: 미실행. 이 세션의 localhost 접근 제한을 우회하지 않았다.
- 데스크톱 Excel 실행/재계산: 미실행. 생성 도구 검사와 구분한다.
- DB·인증·권한·공동편집·자동 알림 발송·실시간 동기화: 미실행.

새 데이터 갱신은 원본 보존→단위·중복·매핑 확인→계산 동등성 검증→공개 허용목록 확인 후 진행한다.
