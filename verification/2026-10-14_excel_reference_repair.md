# 기존 업무 Excel 참조 오류 복구 검증

## 범위

이전 작업에서 발견한 원본 Excel의 참조 오류와 종속 합계를 조사했다. 원본 및 이전 버전을 보존하고 로컬 새 버전만 수정했다. 실제 파일명, 원장 값, 오류 위치와 조치내역은 공개 대상에서 제외한다.

같은 양식의 정상 수식·열 의미가 복구 근거인 항목과 근거가 소실된 과거 집계를 구분했다. 후자는 임의 숫자나 0으로 대체하지 않았다. 날짜 비교 O/X는 신청일의 일치 여부이며 공식 적격 판정이 아니다.

## 실행한 검증

- Excel 16 별도 인스턴스에서 표본 수정 후 허용된 수식과 종속 범위만 계산. 독립 Python 계산과 비교.
- 날짜 일치·불일치·한쪽 누락·양쪽 누락 및 연도별 집계 경계 검사.
- 저장 후 이전 버전과 비교: 허용 범위 외 입력값·수식·저장값 차이 없음. 정의 이름, 차트·슬라이서 보존. 원본 SHA256 동일.
- 변경 영역의 실제 Excel PDF 출력 확인. 원래 숨김 상태와 인쇄 설정은 결과 파일에서 유지.
- `python -m unittest discover -s tests -v`: 40개 통과.
- `npm test`: 22개 통과.
- 수정된 로컬 실자료의 Python·JS 분류 및 전체 snapshot 30조건 일치. 분류 원장행과 기존 유형 보류 유지.
- `npm run build`: 성공. 의존성의 `use client` 및 큰 번들 경고는 남음.
- 로컬 JSON과 독립 HTML을 수정 결과로 재생성. 원장 오류 수를 재계산하고 삽입 데이터의 동일성을 확인.

## 남은 사항

삭제 전 참조·집계 기준이 없는 과거 오류는 미복구다. 오류가 없다는 사실만으로 기존 요약의 업무 의미가 검증된 것은 아니다. 원본 업무 수식 전체 재계산, 과거 현황 전면 확정, 실제 웹 브라우저 조작, DB 연결, 자동 발송, 실시간 동기화, 원격 CI·push·배포는 이번 검증에 포함하지 않았다.
