# ORS 로컬 자동 갱신 검증

## 구현과 실행

- 원본 Excel/ZIP 읽기, 열 이름 매핑, 복합 식별값의 유일성 검사, 자료 날짜·처리일 후퇴 방지, 빈 값/중복/기본정보 변경 보류를 구현했다.
- 기존 수식을 보존하는 데스크톱 Excel 갱신과 Excel 저장 결과 → 로컬 JSON → 독립 HTML 생성을 실행했다.
- 제공된 다운로드 자료는 기준 관리 파일보다 이전 자료여서 덮어쓰기를 보류했다. 실제 최신 입력이 반영됐다고 보고하지 않는다. 마지막 관리 파일 값으로 결과 사본을 생성했다.
- 시험 사본의 고유한 ORS 레코드 상태 1셀 변경을 통해 관리 시트 조회값 → Excel 분류 원장 → Python/JS 필터 집계의 전달을 확인했다. 시험값은 사용자 결과에 포함하지 않았다.

## 확인

- Python 전체 54개 검사 통과. 수량 변경 보류·보조 수식 중복 헤더 검사를 포함한다.
- 웹 23개 검사와 React 프로덕션 빌드 통과.
- 실제 결과의 Python/JS 전체 snapshot 12조건 일치. 변경 시험 1조건도 일치.
- Excel/JSON 원장행 식별과 11개 분류 필드 대조, 원본 해시 및 수식·수동 입력 보존 검사 통과.
- 각 파일의 차트 6개·슬라이서 10개 보존 및 차트 합계 대조. 변경 시험에서 새 수식 오류 없음.
- 최종 결과 엑셀 2개를 데스크톱 Excel에서 읽기 전용으로 다시 열고 차트·슬라이서 보존을 확인했다.
- ORS 갱신 패널의 서버 측 화면 생성(SSR)을 확인했다. 브라우저 클릭 검증을 대신하지 않는다.
- 로컬 스키마 검사와 HTML 내장 데이터 동일성 검사 통과. 빌드 의존성의 use client 및 큰 번들 경고는 남아 있다.

## 미실행·한계

지원하는 모든 ORS 양식의 변경 시나리오를 데스크톱 Excel에서 전수 검증하지는 않았다. 기존 수동 복사 값은 자동 연결로 바꾸지 않았다. 기존 참조 오류와 행정적 판단 보류를 해결한 것은 아니다. 새 브라우저 UI 클릭·모바일 조작, 원격 CI·push·배포, ORS 사이트 직접 수집, 상시 감시, DB·자동 발송은 미실행이다.

실자료 파일·경로·셀별 변경 내역은 로컬 결과 폴더에만 보관한다.
