# 내부 원장 연결 진행현황 · 2026-10-15

## 변경

공개 화면의 진행현황 구역에 로컬 JSON을 선택해 원장 상태를 조회하는 기능을 추가했다. 내부용 독립 HTML은 같은 구역에 로컬 데이터를 자동으로 연결한다. 자료 탐색에도 진행현황 탭을 추가했다. 외부사업과 정보 비공개 원장의 업무구분·국내외·원문 상태·진행상태·담당자·검색 조건을 함께 적용하고, 결과를 50행씩 표시한다. 원본 시트·행 번호를 확인할 수 있다.

공개자료 집계와 내부 원장 집계는 분리한다. 내부 데이터가 없는 공개 화면은 파일 선택 안내를 표시한다. 로컬 JSON 읽기는 브라우저 안에서 수행하며 전송하지 않는다. 실제 원장·JSON·독립 HTML·내부 Excel·세부 검증 결과는 저장소 밖의 로컬 산출물에 보관한다. 원격 push·공개 배포는 수행하지 않았다.

## 검증

- 웹 테스트 27개와 Python 테스트 73개 통과. React/Vite 빌드 성공.
- 실제 원장 전체 행·상태별 합계와 Excel 저장값·웹 결과를 대조했다. Excel 집계의 원장×국내외 조건 9개가 일치했다.
- 실제 Microsoft Excel 16에서 전체·업무별 집계, 원장 선택, 표 필터, 새 상태 조합 감지와 복원을 읽기 전용으로 검증했다. 원본과 결과 파일을 저장하지 않았다.
- 설치된 Edge에서 로컬 파일을 직접 열어 원장·업무 필터, 2페이지, 원본 위치, 초기화, 데스크톱·모바일 표시를 확인했다. 외부 요청과 브라우저 스크립트 오류가 없었다.
- 원본 자료 탐색의 서버 렌더링 검사도 통과했다. 기존 번들 크기 경고는 남아 있다.

검증용 기본 Chromium이 없어 Edge를 사용했다. 보호 환경 밖의 브라우저에서 보호 환경 내부의 로컬 서버로 접속할 수 없어 로컬 HTML을 직접 열어 검증했다. 첫 Excel 검증의 표 필터 해제 호출을 ListObject의 AutoFilter로 한 번 수정하여 완료했다.

## 한계

생성 시점의 원장 추출본이다. Excel 연결원장 안의 필터·집계는 수식으로 동작하지만, 원본 업무 Tool 변경이 웹·새 Excel에 실시간 반영되지는 않는다. 원본 수정 후 자료를 다시 생성해야 한다. 원장의 현재 상태 원문을 그대로 조회하며 공식 검토 단계·기한·승인율을 추정하지 않는다. 기존 기준 미확인 수식과 신청유형 보류를 자동으로 확정하지 않는다.
