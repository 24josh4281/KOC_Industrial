# 신청연도 기본 표시와 쉬운 용어 · 2026-10-15

## 변경

내부 신청 현황을 전체 기간부터 보여주던 문제를 수정했다. 웹과 별도 내부 Excel에서 신청연도 2026을 기본 선택한다. ‘전체 기간’, 과거 연도, ‘신청일 확인 필요’를 구분해 조회한다. 자료 구분을 바꾸어도 신청연도 선택은 유지한다. 업무별 신청 내역과 처리 단계별 현황을 먼저 보여주고, 최근 신청부터 목록을 정렬한다.

진행현황의 사용자 문구를 ‘신청 내역’, ‘처리 현황’, ‘원본 보기’, ‘확인 필요’로 바꾸었다. Excel에는 ‘신청 목록’ 탭을 제공한다. 원본 파일의 셀 값과 계산식은 수정하지 않는다. 연도는 실제 신청일에서만 확인하며 월까지만 있는 날짜에도 임의 일자를 부여하지 않는다. 같은 사업의 평가·인증·비공개 신청은 별도로 표시한다. ‘신청연도 현황’을 ‘그해에 처리한 모든 업무’ 또는 ‘현재 진행 중인 모든 업무’로 해석하지 않도록 설명을 표시한다.

## 검증

- 웹 테스트 28개 통과. React/Vite 빌드 성공.
- Edge의 실제 로컬 화면에서 기본 연도, 업무별 숫자, 자료 구분 변경 후 연도 유지, 전체 기간·신청일 확인 필요 선택, 진행상태 선택, 페이지 이동, 원본 보기, 초기화와 모바일 표시를 확인했다.
- Excel은 대표 자료로 연도 선택, 잘못된 날짜 제외, 상태별 합계를 먼저 확인하고 같은 방식으로 전체 자료에 적용했다. 전체 자료의 기간·자료 구분·국내외 12개 조건이 독립 집계와 일치했다. 저장된 모든 내역의 입력값·연도 수식 결과·원본 파일 해시가 일치하며 저장된 수식 오류는 없었다.
- Microsoft Excel 16에서 기본 연도, 전체 기간, 신청일 확인 필요, 비공개 신청 선택, 표의 연도 필터와 잘못된 날짜 제외를 읽기 전용으로 검증했다. 검사 결과는 저장소 밖의 해당 산출물 검사 파일에 보관한다.

## 범위

공개 통계의 기간 조건과 내부 신청연도의 조건은 별도다. 이전 연도에 신청한 업무는 ‘전체 기간’이나 해당 신청연도에서 확인한다. 신청일이 없는 내역은 어느 연도에도 임의로 포함하지 않는다. 자료 반영일 이후의 변경은 새로 반영해야 한다. 비공개 자료와 세부 숫자는 로컬 산출물에만 저장하며 원격 push·공개 배포는 수행하지 않는다.
