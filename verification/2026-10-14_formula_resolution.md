# 기존 계산 오류와 미확인 기준 분리

## 원인과 조치

저장된 오류값만 세던 검사는 수식 본문에 끊어진 참조가 있는데도 이전 저장값이 0인 셀을 놓쳤다. 수식 본문과 연결 합계까지 함께 검사하도록 보완했다.

로컬 관리 파일의 삭제된 참조와 확인되지 않은 날짜·상태 열 연결을 조사했다. 삭제 전 기준을 입증할 자료가 없어 해당 계산은 `기준 미확인`으로 보류했다. 숫자 복원이나 공식 현황 확정으로 보고하지 않는다. 원본 및 셀별 이전 수식·변경 사유는 로컬에 보존한다.

연결 합계에는 미확인 값이 있으면 같은 상태를 표시하는 조건을 추가했다. `IFERROR(...,0)`을 사용하지 않는다. 조건부 합계는 실제 조건에 해당하는 행을 확인하여 다른 연도의 정상 계산을 불필요하게 막지 않았다. 실제 0과 미확보를 구분한다.

## 검증

- Python 57개 검사와 웹 24개 검사 통과. React 빌드 통과. 기존 번들 크기·의존성 경고는 남아 있다.
- 실제 Excel에서 표본을 먼저 확인하고 미확인·0·정상값 복원·예상하지 않은 오류의 4조건을 시험했다.
- 수정 범위 밖의 원본 값·수식·셀 서식 보존을 대조했다. Excel이 글꼴 자원 번호를 재배치하므로 번호 대신 셀에 적용된 서식을 비교했다.
- 원본은 저장하지 않고 새 사본을 만들었다. Excel의 기존 차트·슬라이서 보존을 위해 데스크톱 Excel로 편집·계산했다.
- ORS 갱신 절차를 수정 사본으로 다시 실행했다. 실자료 Python/JS 집계 12조건, 원장 분류 11필드, 자료 요약·계산 품질 지표 동등성 검사를 통과했다.
- 최종 엑셀 2개를 읽기 전용으로 다시 열어 차트·슬라이서와 대표 보류값을 확인했다. 관리 행·신청·검토 이력·기존 보류 및 입력 원본 해시는 유지됐다.
- 수정 영역 4곳을 렌더링해 확인했고 계산 확인 패널의 SSR 검사를 통과했다. SSR은 브라우저 클릭 검증이 아니다. 출력별 결과는 로컬 검증 기록에 보관한다.
- 검증 완료 후 기존 실행기의 최근 결과를 새 사본으로 연결했다. 이후 ORS 파일 갱신도 수정 사본을 기준으로 이어진다.

## 한계

미확인 기준을 복원한 것은 아니다. 삭제된 월별 집계 기준·과거 배분 항목·비율 분자와 분모가 확보되면 원래 목적에 맞는 수식으로 복원해야 한다. 이번 재계산은 수정 셀과 영향을 받는 연결 수식 범위이다. 전체 원장 수식의 업무 의미를 재인증하지 않았다. DB 연결·사이트 직접 수집·공개 push·배포·브라우저 클릭 검증은 미실행이다.
