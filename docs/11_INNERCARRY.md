# 이너캐리 웹 디자인 적용

제공된 이너젠·이너캐리 소개자료 v4.1의 구조·색·글꼴 정보를 읽고 기존 이너캐리 스타일 명세와 대조했다. PPT 원본은 수정하거나 공개하지 않는다.

- 네이비 #0B1739: 제목과 핵심 수치
- 블루 #2F62F0: 조작·진행·차트
- 흰색 / #F8FAFC / #EEF2FF: 본문과 구획
- #475569 / #E2E8F0: 보조 설명과 구분선
- #991B1B: 실제 기한 초과
- IBM Plex Sans KR 우선, Noto Sans KR·맑은 고딕 대체. 폰트 파일을 외부에서 내려받거나 포함하지 않음.

누적 현황 → 신청·검토 → 업무 알림 → 엑셀 연결 순으로 배치한다.
참조 PPT의 화면 비율·고객 사례·실적·연락처·제품 화면은 대시보드 내용으로 복사하지 않는다.
INNerCarry STYLE은 디자인 참조 표기이며 별도 공식 로고를 재현한 것이 아니다.
엑셀은 기존 수식·차트와 서식을 보존했다. 이너캐리 디자인을 반영한 신규 엑셀로 오인하지 않도록 안내한다.
