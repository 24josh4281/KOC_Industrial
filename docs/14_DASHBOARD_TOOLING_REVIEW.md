# 대시보드 도구 반영 점검 · 2026-10-14

사용자가 제시한 프로젝트를 현재 저장소의 패키지, 화면 import, 실행 범위와 대조했다. 프로젝트 링크는 설계 참고 자료이며, 링크를 제시한 것만으로 설치·연결·운영 완료가 되지는 않는다.

| 도구 | 실제 반영 상태 | 이번 화면 고도화에서 사용한 범위 |
|---|---|---|
| [Apache ECharts](https://github.com/apache/echarts) | `web/package.json`에 설치되어 공개 추이와 표준 원장 차트에 사용 중 | 로컬 관리 Tool의 신청연도별 원장행 분포를 SVG 막대 그래프로 추가. 그래프 아래 분류별 수치 버튼을 보존해 키보드 선택과 값 확인을 지원 |
| [TanStack Table](https://github.com/TanStack/table) | 설치되어 표준 원장 표에서 정렬·페이지 처리에 사용 중 | 로컬 관리 Tool 원장 표에도 전체 조회 결과 정렬과 50행 페이지 처리 적용. 원본 시트·행 링크 유지 |
| [Supabase](https://github.com/supabase/supabase) | `supabase/migrations/001_kets_core.sql` 초안과 RLS 수용계획만 존재 | 이번 변경에서 연결하지 않음. 실제 프로젝트 SQL 적용·인증·권한 시험 없음. 내부 원장을 공개 정적 사이트나 외부 DB로 보내지 않음 |
| [Evidence](https://github.com/evidence-dev/evidence) | 의존성·실행 코드 없음 | 근거와 해석 범위를 함께 제시하는 보고서 구성의 참고만 가능. 별도 BI 서비스는 구축하지 않음 |
| [Metabase](https://github.com/metabase/metabase) | 의존성·실행 코드 없음 | 질문별 탐색·필터 구성의 참고만 가능. DB가 없는 현 단계에서 별도 서비스는 구축하지 않음 |
| [Perspective](https://github.com/perspective-dev/perspective) | 의존성·실행 코드 없음 | 큰 표의 피벗·스트리밍 확장 후보. 현재 11분류 교차표는 기존 로직을 유지하며 Perspective 엔진을 설치하지 않음 |

제시된 YouTube 영상 2개는 이번 환경에서 원문·자막을 확인하지 못했다. 영상 내용의 기능이나 디자인을 확인했다고 표시하지 않는다.

## 이번 변경의 업무 의미

- 연도 그래프와 기존 수치 목록은 동일한 필터 결과를 쓴다. `미확보`는 연도 축에서 별도 범주로 남고 실제 확인된 0과 섞이지 않는다.
- 표는 선택한 업무구분·분류·검색 결과 전체를 정렬한 다음 50행씩 표시한다. 원본 값과 계산식은 수정하지 않는다.
- 그래프와 표의 수치 단위는 **관리 Tool 원장행**이다. 고유 신청, 방법론, 등록 또는 승인 통계로 해석하지 않는다.
- 디자인 색상은 기존 이너젠·에너지공단 참고형·정부 KRDS 참고형 설정을 따른다. 그래프 값 확인용 수치 버튼을 함께 제공한다.

## 검증 경계

웹과 Python의 같은 분류 집계 검사, React 빌드, 실제 로컬 JSON 서버 렌더링 및 출력 패키지의 포함 여부를 확인한다. 실제 브라우저 클릭·모바일 기기 조작, Excel 재계산, DB 연결·RLS, 외부 배포는 별도 실행 증거 없이는 완료로 표시하지 않는다.
