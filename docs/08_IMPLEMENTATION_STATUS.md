## 2026-10-14 관리 Tool 연동·분류 조회 추가

- 원본 관리 Tool을 보존한 로컬 새 버전에 분석 시트 3개, 편집 가능한 차트 6개, 실제 Excel 슬라이서 10개를 추가했다. 원본 셀을 직접 참조하며 표 필터와 모든 집계가 연결된다. 각 원본 시트에 추가 50행까지 연결하고 범위를 명시한다.
- 웹 자료 탐색에 11분류 복수 선택, 검색, 그래프 조건 선택, 자유 교차표, 정확한 원본 행 이동을 추가했다. 공개 저장소에는 범용 코드와 합성 테스트만 포함한다.
- 신청·사업·인증의 단위를 유지하고 원장행으로 표시한다. 미확보·월까지만 확인되는 날짜·보류·원본 오류를 따로 표시한다. 기존 보류 항목은 자동 확정하지 않는다.
- Python 40개·Node 22개 검사, Python/웹 실자료 30조건 비교, React 빌드 및 실자료 서버 렌더링을 실행했다. Excel 16에서 슬라이서·표 필터 29조건, 조건 해제, 원본 셀 변경, 예비 행 추가와 신규 연도 슬라이서 반영을 확인했다. 시험값은 저장하지 않았다.
- 이번에 데스크톱 Excel에서 실행한 것은 새 분석 시트 계산과 위 연결 동작이다. 기존 모든 업무 수식을 새로 계산한 것은 아니다. 기존 수식·저장값 보존의 최종 비교 결과는 이번 verification 기록을 따른다.
- 새 웹 화면의 실제 브라우저 클릭·모바일 점검, DB 연결, 자동 발송, 실시간 동기화, 이번 원격 push·배포는 미실행이다. 엑셀 검토 후 게시한다는 요청을 유지한다.
- 사용 방법과 제한은 [관리 Tool 연동·분류 조회](09_MANAGEMENT_VIEWS.md)를 참고한다.
