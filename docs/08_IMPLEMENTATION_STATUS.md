## 공개 실자료 분석 추가분

- 기본 웹 화면과 신규 엑셀에 ORS 공개 이력의 선택한 33개 방법론·40개 버전을 반영했다. 산업부문 전수 통계는 아니다. 각 코드에 공개 출처 URL과 수집 해시를 보존했다.
- 유효시작일 상한·비교연도·분야·등록형태·개정 경험·검색 조건을 교차 적용한다. 최초·개정·누적, 전년 동기간, 분야 구성·집중, 버전 분포, 최근 변경, 경과일 분포·중앙값·장기 관찰을 제공한다.
- 엑셀은 별도 버전으로 제작했고 기존 합성 예시 원장은 보존했다. 남색 KPI, 파랑 차트 2개, 노란 조건 입력, 수식 재계산, 원본/출처 열을 제공한다. 웹과 동일한 분석 정의를 사용하지만 실시간 동기화하지 않는다.
- Python 36개와 웹 18개 검사 통과. 신규 공개 집계의 전체 Python·JS 결과 79조건, 기존 집계 96조건, 업무기한 12조건을 비교했다.
- 엑셀 조건 변경 19회 재계산 결과를 웹 집계와 대조했다. 저장한 XLSX의 33/40개 원본 값·버전 문자열·주요 수식 저장값·연도 합계·차트 2개·오류 없음 검사를 통과했다. 5개 시트를 렌더링해 확인했다.
- React 프로덕션 빌드와 공개 파일 허용목록 배치 성공. 비공개 원장·매핑 검토 파일은 배포 대상에 넣지 않았다. 원격 CI·Pages 및 실제 브라우저 확인은 각 실행 기록을 기준으로 판단한다.
- 진행 중 신청·보완기한·승인/반려율·심사기간은 공개자료 미확보다. 내부 원장의 미확정 매핑은 유지한다. 자동 알림 발송·DB·인증·공동편집 및 데스크톱 Excel 재계산은 미실행이다.
