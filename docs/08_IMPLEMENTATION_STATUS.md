## 2026-10-14 ORS 파일 자동 갱신 추가

- ORS Excel/ZIP → 기존 ORS 시트 → 연결 수식 계산 → Excel/JSON/로컬 웹 동시 생성 절차를 구현하고 실행했다. [실행 방법과 범위](13_ORS_REFRESH.md)를 참고한다.

- 유일하게 연결된 상태·처리일·이력을 반영한다. 이전 자료, 신규·중복 연결, 공란, 수량·기본정보 변경은 보류하고 수식·수동 업무 열·기존 유형 보류를 유지한다.
- 실제 입력은 기준 관리 파일보다 오래된 자료로 확인되어 덮어쓰지 않았다. 별도 사본에서 상태 변경의 Excel·웹 전달을 확인했다. 원본 저장 오류 전체 복구나 최신 ORS 웹 수집 완료를 뜻하지 않는다.
- 갱신 성공 결과의 Python/JS 12조건, Excel 11분류, 차트·슬라이서·원본 보존 검사를 실행했다. 검증 실패 시 최근 결과를 바꾸지 않는다. 시험 내용과 범위는 [검증 기록](../verification/2026-10-14_ors_refresh.md)에 구분한다.
- 로컬 검토 계약 1.1과 ORS 연동 현황 화면을 추가했다. 운영 dataset·SQL·DB는 변경하지 않았다. 상시 감시·사이트 직접 연결·이번 공개 배포는 미실행이다.
- 이전 계산 근거가 없는 396셀은 사용자 확인에 따라 `기준 미확인`으로 계속 보류한다. 추가 원장 없이 숫자를 임의 복원하지 않는다.

- 실제 Excel의 부분 재계산, 수정 범위 밖 값·수식·저장값 보존, 차트·슬라이서 보존을 확인했다. 전체 원본 수식 재계산이나 과거 업무 집계의 완전한 복구를 뜻하지 않는다.

- 별도 화면 오류 메시지는 미제공 상태이며, 이번 점검 대상은 앞서 발견한 Excel 저장 오류다. DB·새 웹 브라우저 조작·원격 push·배포는 미실행이다.
