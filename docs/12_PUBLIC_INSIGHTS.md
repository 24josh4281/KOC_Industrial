# 공개 실자료 분석

2026-10-14 ORS의 로그인 없는 방법론 목록과 각 코드의 공개 이력 페이지를 확인했다. 제공 참고 코드 33개를 공개 화면의 코드로 다시 대조한 **33개 방법론·40개 버전 확인분**이다. 산업부문 전수 통계가 아니다. 분야·등록형태는 공개 원문이며 내부 산업/발전 분류는 가져오지 않았다.

공식 목록: https://ors.gir.go.kr/home/orme010/activeList.do?menuId=12

공개 목록은 326행에 분야 중복 1행을 안내한다. 이 숫자를 고유 방법론 수로 복사하지 않았다. 이번 분석은 선택한 33개 코드의 공개 이력을 기준으로 독립 집계한다. 공개 HTML의 특수문자 표기와 명칭 오탈자가 있는 2개 항목도 최종 연결은 상세 화면의 고유 코드로 확인했다.

## 가능한 질문

| 시나리오 | 기준·단위 | 기능 |
|---|---|---|
| 확인된 전체 규모 | 고유 코드 / 코드별 버전 | 방법론·버전 분리, 목록·CSV·공개 이력 |
| 연도별 최초·개정 | 유효시작일, 버전 | 연간 막대와 정확한 수치표 |
| 누적 흐름 | 최초 버전 유효시작일, 방법론 | 누적 그래프·연도표 |
| 전년 비교 | 선택연도 1월 1일~상한일 vs 전년 동기간 | 증감 건수·증감률. 전년 0이면 비율 계산 불가 |
| 분야 구성·집중 | 수집 시점 공개 분야, 방법론 | 분야별 비중, 상위 3개 비중 |
| 등록형태 비교 | 신청등록 / 직권등록 | 교차 필터·분포 |
| 개정 경험 | 상한일 내 revision 버전 1개 이상, 방법론 | 경험 유무 필터·비중 |
| 버전 분포 | 상한일 내 최신 유효시작 버전 | Ver별 방법론 수 |
| 최근 변경 | 기준일을 포함한 N일, 버전 | 30/90/180/365일, 목록 연결 |
| 장기 관찰 | 최신 버전 유효시작 후 1/3/5년 초과 | 경과 구간·중앙값·목록. 효력 판단 아님 |
| 세부 근거 | 코드·명칭 검색, 분야·등록형태·개정 조건 | 정렬·상세 이력·출처 링크·CSV |
| 과거 이력 | 현재 공개 이력에서 상한일까지 발생분 | 당시 전수 현황·당시 분류를 복원했다고 표시하지 않음 |

엑셀의 `분석조건` 노란 셀을 변경하면 같은 수식이 재계산된다. 방법론/버전 표에서 `포함=1`을 필터하면 동일 모집단을 확인할 수 있다. 웹에서 바꾼 조건을 엑셀 다운로드에 자동 저장하거나 실시간 동기화하지는 않는다. 엑셀 다운로드는 기본 조건의 고정 확인본이다.

## 공개자료로 판단할 수 없는 항목

진행 중 신청, 담당자, 보완요청 상세·제출기한, 심사기간, 승인/반려율은 **공개자료 미확보**다. 공개된 방법론을 신청 모집단으로 삼아 승인율을 만들지 않는다. 유효시작일을 최초등록일·승인일로 대체하지 않는다. 장기 미변경을 효력 상실이나 법정기한 초과로 판단하지 않는다.

내부 신청·검토이력, 연락처·메모·원본파일을 공개 데이터에 포함하지 않는다. 미확정 내부 매핑은 별도로 보류한다. 공개자료 범위에서 신청 알림이 보이지 않는 것은 누락된 0이 아니라 근거 미확보다.

## 데이터 계약·검증

- 읽기 전용 공개 카탈로그는 `schemas/public_catalog.schema.json` v1.0.0. `methods`와 `versions`를 별도 배열로 유지한다.
- 기존 운영 dataset v1.0.0, 표준 XLSX 입력 계약, SQL은 변경하지 않는다. 공개 엑셀은 운영 `from-xlsx` 입력 형식이 아니다.
- 각 공개 항목은 ORS 이력 URL과 수집 HTML의 SHA-256을 가진다. 연락처·신청·내부 상태 필드는 스키마에서 허용하지 않는다.
- Python·JavaScript의 같은 조건 전체 결과 비교와 엑셀 입력 변경·수식 재계산 대조를 실행한다.
- 날짜/분야/유형/검색 조건을 적용한 뒤 방법론·버전·각 분포 총합을 교차 확인한다.
- DB 연결, 로그인, 공동편집, 이메일·문자 자동 발송은 이번 범위에 없다.

공개 자료의 권리는 원 출처에 있으며 코드의 MIT 라이선스로 원자료를 재허가하지 않는다.
