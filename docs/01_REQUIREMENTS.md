# 01. 요구사항과 범위

## 목표

산업부문 외부사업 방법론의 누적 고유 등록, 신규·개정 추이, 적용상태, 검토 중 신청, 승인 후 등록대기, 보완 대기를 한 화면에서 확인. 동일 원장을 엑셀과 웹에 사용.

## v1 화면

종합 현황 / 등록 방법론 / 검토 신청 / 데이터 품질·출처. 공통 필터: 발생 기준일, 지식 기준일, 산업·전환 범위, 선택연도. 목록 검색·상세이력·CSV 내보내기. 기본 산업 범위, 산업+전환은 별도 선택.

## 수용 기준

고유 ID가 중복되면 입력 거부. 개정 버전 추가로 누적 고유 방법론 수 불변. 최초등록일 미확인분은 전체 등록확인 KPI에는 포함하되 연도별 차트에는 미포함. 검토자료 미확보는 0으로 표시 금지. 완료와 미완료 기간 혼합 금지. 발생일·기록일 기준으로 과거 단계 재구성. 보완요청으로 단계 진입일 초기화 금지.

## v1 제외

실제 ORS 전수수집, 비공개 검토현황 자동조회, 법적 적합성 판정, 개별 외부사업 등록대장, KOC 발급 통계, AI 승인판정, 운영 DB·로그인·공동편집·원격 배포.

## 사용자 역할 목표

조회자: 소속 워크스페이스 조회. 검토자: 신청·증빙·검토 사건 추가. 관리자: 구성원·분류·원장 반영 관리. 공식 승인 근거 없는 내부 상태 업데이트는 별도 업무기록으로 취급. 현재 HTML은 로그인 없는 로컬 조회 전용이고 위 역할 기능은 SQL·요구사항 단계.
