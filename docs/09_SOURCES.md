# 09. 공식 출처와 기술 참고

확인일 2026-10-13. 아래는 설계 참고이며 합성 예시 행의 데이터 출처가 아님.

| 출처 | 링크 | 적용한 내용 / 한계 |
|---|---|---|
| 온실가스종합정보센터 ORS 방법론 목록 | https://ors.gir.go.kr/home/orme010/activeList.do?menuId=10 | 방법론 분야·유효시작일·등록형태·이력·파일·다운로드 확인. 공식 전체목록 건수를 산업부문 고유 건수로 사용하지 않음 |
| 한국에너지공단 방법론 승인 절차 | https://offset.energy.or.kr/methodology/agree.do | 신규 신청·검토·협의·심의·등록 흐름 참고. 본문 기관명 혼재 가능, 현행 법령 판정자료로 단독 사용 금지 |
| Supabase RLS 공식 문서 | https://supabase.com/docs/guides/database/postgres/row-level-security | RLS와 권한 함께 설정, 서비스 키는 서버측에만 보관 |
| Vite 정적 배포 공식 문서 | https://vite.dev/guide/static-deploy.html | 상대경로·GitHub Pages 배포 구분 |
| shadcn/ui 공식 저장소 | https://github.com/shadcn-ui/ui | 확장 가능한 구성요소 접근 참고. 현재 패키지에서 정식 UI 이식 완료 아님 |
| Apache ECharts | https://github.com/apache/echarts | React 목표 차트 엔진 |
| TanStack Table | https://github.com/TanStack/table | React 표 정렬·페이지 처리 |
| TanStack Query | https://github.com/TanStack/query | React 조회 결과 관리 |

공식 검토대장 전체의 공개 API를 확인한 것은 아니며 자동조회 가능성을 보장하지 않음. 수집기 구현은 원본 다운로드·이용조건과 승인된 내부 자료의 구조를 확인한 뒤 진행.
