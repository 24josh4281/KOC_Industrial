# 03. 지표 정의

상세 기계판독 정의는 config/metrics.json. 화면상의 개수 단위는 방법론/버전/신청을 명시.

| 지표 | 계산 |
|---|---|
| 누적 고유 방법론 | 원장의 first_registered_on 또는 registration_confirmed_on이 기준일 이하이며 기록일이 지식기준일 이하인 고유 ID |
| 적용 가능 확인 | 위 모집단 중 기준일까지 마지막 상태이력이 active |
| 선택연도 신규 | 최초등록일의 연도가 선택연도인 등록확인 방법론 |
| 선택연도 개정 | revision 버전의 registered_on이 선택연도·기준일 이내. effective_from 대체 금지 |
| 검토 중 신청 | submitted/review/consultation/committee인 접수 신청 |
| 승인·등록대기 | approved인 신청. registered와 별도 |
| 보완 대기 | 검토 중 신청 중 마지막 이력 waiting=true |
| 관리기준 초과 | 검토 중 신청의 현재단계 경과일 > 내부기준(기본 45일 예시). 법정기한 아님 |
| 완료기간 중앙값 | registered/rejected/withdrawn으로 끝난 신청의 최종단계 진입일−접수일 중앙값. 대기·미완료 제외 |

연도별 누적선은 등록연도 확인분만 계산. 전체 KPI−최종연도 누적선의 차이는 등록연도 미확인분이어야 함(같은 범위·기준일). 차트에는 해당 설명을 항상 표시.

coverage missing: KPI null, '자료 미확보'. partial: 확보분 집계이며 전체시장 건수로 사용 금지. complete: 자료 담당자가 대상 범위 전수확보를 확인한 경우만 선택. demo: 전량 합성 예시. 공개승인 필터로 일부만 내보낸 자료는 complete를 유지하지 않음.

처리기간은 달력일·총기간. 보완기간 제외 순수 검토일수는 v1 미구현. 전환율·승인율은 동일 접수집단과 관측 종료시점이 정해지기 전 제공하지 않음.

## 보완서류 제출기한 알림

보완 대기(waiting=true)이며 검토 중인 신청만 대상으로, 제출기한(due_on) − 발생 기준일을 달력일로 계산한다.
음수는 초과, 0은 오늘 마감, 양수는 D-n이다. 선택한 n일 이내와 초과·기한 미확인 항목을 표시한다.
기한이 없으면 미확인이며, 검토 자료 자체가 없으면 모든 알림 KPI는 null이다.
완료·철회·반려 및 보완 대기가 해제된 신청은 제외한다. 최신 이력의 기한을 사용하므로 이력 작성 시 현행 기한을 명시해야 한다.
화면 알림과 CSV 제공 범위이며 자동 메시지 발송·법정기한 계산은 아니다.
